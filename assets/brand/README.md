# HC Labs Brand Asset

File `hc-labs-logo.png` adalah sumber logo utama yang dipakai sidebar HC Labs.

Untuk mengganti logo berikutnya:

1. Ganti file `assets/brand/hc-labs-logo.png` dengan file PNG baru.
2. Pertahankan format PNG dan rasio yang sesuai untuk lockup logo.
3. Commit dan push file tersebut ke branch `main`.
4. Deployment frontend akan menggunakan asset baru tanpa perubahan pada `index.html`.

Referensi path di frontend: `assets/brand/hc-labs-logo.png`.
